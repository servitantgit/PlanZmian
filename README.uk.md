# 📅 Plan Zmian

**Język / Language / Мова:** [Polski](./README.md) · [English](./README.en.md) · **Українська**

PWA-застосунок для роботи з графіками змін 4 бригад у 3-змінній системі (Ранкова/Денна/Нічна). Замінює паперовий календар у бейджі.

**Демо:** [https://planzmian.pages.dev/](https://planzmian.pages.dev/)

## ✨ Основні можливості

- 📊 **4 бригади** (A/B/C/D) з системою 3 змін (R/P/N) + Вихідні + Відпустка
- 🏠 **3 основні види**: Дашборд, Місяць, Таблиця
- 📈 **Режим Рік** — розгортає Місяць/Таблицю на весь рік (12 міні-календарів/таблиць)
- ✏️ **Редагування графіка** (автозбереження; ліміт відпустки в режимі редагування 🌴)
- 🌴 **Відпустки** з лімітом на бригаду й автоматичним підрахунком робочих днів
- ⏱ **Надгодини** з автокатегоризацією (+50%/+100%/+200%) — для робочих днів І для вихідних/свят
- 📝 **Нотатки** до будь-якого дня
- 🔍 **Пошук** змін, вихідних, відпусток
- ⚖️ **Порівняння бригад** (Ctrl+клік)
- 🎨 **2 теми**: світла/темна (перемикач у верхній панелі)
- 🌐 **Багатомовність**: польська, англійська, українська (перемикач 🌐 у верхній панелі)
- 📱 **PWA** — встановлення на телефон, офлайн-режим, повідомлення
- 📱 **Поділитися застосунком** — посилання + QR-код + системний шеринг (SMS, месенджери)
- 🔄 **Автооновлення** — повідомлення про нову версію, що застосовується одним кліком
- 🔗 **Контекстний шеринг** — посилання саме на той вид, який ви бачите
- 📥 **Експорт .ics** у календар, **друк**
- ☁️ **Google Drive** — опційний бекап/синхронізація (за замовчуванням вимкнено; увімкніть у Налаштування → Приватність)

## 🚀 Швидкий старт

1. Відкрийте [https://planzmian.pages.dev/](https://planzmian.pages.dev/)
2. Виберіть бригаду (A/B/C/D) і рік
3. Дашборд покаже сьогоднішню зміну з таймером (триваюча після опівночі зміна N попереднього дня залишається активною; надгодини `po` можуть її подовжити — опція дати в Налаштування → Загальні)
4. Перемикайте види через верхнє меню

**Стилі клітинок:** у Персоналізації доступні три варіанти: повна заливка, спокійна смужка та кольорова рамка. У останньому варіанті колір рамки клітинки й кола навколо дати відповідає зміні.

**Деталі функцій:** ☰ Меню → ❓ Довідка / FAQ · код: [GitHub](https://github.com/servitantgit/Graffik)

## 📱 Встановлення як PWA

### Android (Chrome)

- Меню браузера (⋮) → «Додати на головний екран»
- Або: ☰ Меню → 📲 Встановити застосунок

### iPhone / iPad (Safari)

1. Відкрийте сторінку в **Safari** (не в іншому браузері!)
2. Торкніться **Поділитися** ⬆️ внизу екрана
3. Прокрутіть вниз → **«Додати на екран «Домівка»»**
4. Торкніться **«Додати»**

Після встановлення застосунок працює на весь екран, без адресного рядка, і доступний офлайн.

## 🔗 Шеринг і URL-параметри

Функція **🔗 Поділитися видом** у боковому меню створює посилання саме на те, що ви бачите. Одержувач побачить той самий вид.

### URL-параметри

| Параметр | Значення                            | Приклад      | Необовʼязковий |
| -------- | ----------------------------------- | ------------ | -------------- |
| `view`   | Тип виду: `dashboard`, `month`, `table` | `view=month` | Ні         |
| `y`      | Рік                                 | `y=2026`     | Ні             |
| `m`      | Місяць (1-12)                       | `m=8`        | Так\*          |
| `d`      | День (1-31)                         | `d=10`       | Так\*          |
| `brig`   | Бригада (A/B/C/D)                   | `brig=C`     | Так\*          |
| `rok`    | Режим Рік (1 = увімкнено)           | `rok=1`      | Так\*          |

\* Параметр додається автоматично, якщо він має сенс для цього виду.

### Приклади URL

```
# 10 серпня, бригада C
?view=month&y=2026&m=8&d=10&brig=C

# Весь серпень, бригада C
?view=month&y=2026&m=8&brig=C

# Річний вид, бригада C
?view=month&y=2026&brig=C&rok=1

# Таблиця — весь рік
?view=table&y=2026&rok=1
```

## 🛠 Для розробників

### Технологічний стек

- **Vanilla JavaScript** (ES2020+, без фреймворків, без системи збірки)
- **HTML5 + CSS3** (Custom Properties, Flexbox, Grid)
- **i18n**: власна проста система перекладів у `js/i18n/` (3 мови, без зовнішніх залежностей)
- **PWA**: Service Worker + Web App Manifest
- **Google Drive API** (OAuth 2.0)
- **Хостинг**: GitHub Pages
- **CI/CD**: GitHub Actions (автоверсіонування кешу SW при кожному push)

### Вимоги

- Сучасний браузер із підтримкою ES2020, Service Worker, localStorage
- **Увага**: PWA і JS-модулі потребують HTTP (не працюють з `file://`)

### Локальний запуск

```bash
# Python 3
python -m http.server 8000

# Node.js (якщо є http-server)
npx http-server -p 8000
```

Далі відкрийте: `http://localhost:8000`

### Запуск тестів

```bash
node tests/run.js
```

Працює на будь-якій версії Node 18+. Форма `node --test "tests/*.test.js"` працює лише з Node 21+, бо власне розкриття glob у позиційних аргументах `--test` з’явилося тільки в цій версії.

## ⌨️ Гарячі клавіші

### Режим редагування

| Клавіші                   | Дія                                                              |
| ------------------------- | ---------------------------------------------------------------- |
| `R` / `P` / `N` / `W`     | Вибір зміни для «малювання»                                      |
| `C`                       | Режим циклу (ротація змін)                                       |
| `O`                       | Режим надгодин (до/після зміни І робота у вихідний/свято)         |
| `Ctrl+Z`                  | Скасувати останню зміну                                          |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Повторити скасовану зміну                                        |
| `Ctrl+S`                  | Зберегти всі зміни                                               |
| `Esc`                     | Вийти з режиму редагування                                       |

### Навігація

| Клавіші   | Дія                                            |
| --------- | ---------------------------------------------- |
| `←` / `→` | Попередній/наступний місяць                    |
| `E`       | Увімкнути/вимкнути режим редагування           |
| `Esc`     | Закрити попап/модалку або вийти з редагування  |

### Вибір бригади

| Дія            | Результат                                            |
| -------------- | ---------------------------------------------------- |
| `Клік`         | Змінити активну бригаду                              |
| `Ctrl + клік`  | Порівняти з іншою бригадою (підсвічує спільні зміни) |

## 🌐 Мови

Застосунок підтримує 3 мови (вибір кнопкою 🌐 у верхній панелі):

- 🇵🇱 **Polski** (за замовчуванням)
- 🇺🇸 **English**
- 🇺🇦 **Українська**

Мова визначається автоматично з налаштувань браузера при першому запуску. Вибрана мова зберігається в localStorage і залишається після перезапуску.

**Для розробників** — додавання нових перекладів:

1. Відкрийте `js/i18n/pl.js` (або en.js/uk.js) — додайте новий ключ зі значенням
2. **Важливо**: додайте той самий ключ у ВСІХ 3 файлах
3. У HTML використовуйте `data-i18n="ключ"`, у JS: `t('ключ')` / `t('ключ', {param: 'значення'})`

Паритет ключів, плейсхолдери й динамічні префікси перевіряє `node tools/i18n-audit.js`. Секція «unused keys» у цьому звіті — лише інформаційна: ключі, до яких звертаються непрямо (`t(key)` зі змінної, мапи відповідностей, назви, що складаються динамічно), статичний аналіз не бачить, тому нічого не варто видаляти, спираючись лише на цей список.

## 💾 Збереження даних

Застосунок зберігає дані в двох місцях:

1. **localStorage** (основне) — відпустки, надгодини, нотатки, налаштування, правки графіка
2. **Google Drive** (опційно, **за замовчуванням вимкнено**) — бекап і синхронізація між вашими пристроями. Увімкніть перемикач у Drive card у боковому меню, потім увійдіть.

Усі налаштування синхронізації в одному місці: **⚙ Опції синхронізації** у боковому меню → блок Google Drive. Панель містить:
- **Режим синхронізації** — Автоматична (фонові перевірки) або Тільки вручну (без вікон логування Google у фоні — рекомендовано).
- **Зміни** — порівняння локальних даних із Drive (відпустки, надгодини, нотатки, власні зміни).
- **Дії** — Надіслати / Завантажити.

**Увага:** дані в localStorage можна втратити при очищенні памʼяті браузера. Робіть бекап через ☁️ Google Drive або експортуйте поточний вид (ICS / друк).

## 🔒 Приватність

Усі дані зберігаються локально в браузері користувача. Застосунок не збирає аналітику і не надсилає дані на наші сервери. Повний текст: **[Політика конфіденційності](./privacy.html)** (UK / EN / PL).

**Режим приватності** (Налаштування → Дані та приватність або перемикач у меню) ховає особисті дані на екрані (відпустки, надгодини, нотатки, власні зміни) і показує лише заводський графік. Це незалежно від входу в Google.

**Google Drive** — лише опційний бекап:

- За замовчуванням вимкнено — застосунок ніколи не запитує акаунт Google.
- Після увімкнення та входу дані зберігаються лише у *вашій* папці даних застосунку Google Drive (scopes `drive.file` + `drive.appdata`).
- Вихід або вимкнення опції очищає локальний токен; файл у Drive залишається, доки ви не видалите його або не відкличете доступ у акаунті Google.

## Адмін: публікація заводського графіка

Джерело правди — **Cloudflare D1** (`GET/PUT` через Pages Functions). Статичний `js/schedules/gillette/YYYY.js` — лише офлайн-fallback.

1. Увійдіть Google під адмін-акаунтом.
2. Admin Center → Factory → **Почати редагування** (чернетки R/P/N/W локально).
3. У панелі режиму малювання натисніть **📤** (або «Опублікувати» в Admin Center).
4. Усі клієнти підхоплюють нову `revision` з `/api/schedule` (без git/deploy).

Опційно: **Експорт `.js`** лишається резервним шляхом у git. Деталі: [docs/PROJECT_DOCS.md](./docs/PROJECT_DOCS.md) §3.2, [docs/ADMIN_BACKEND_SPEC.md](./docs/ADMIN_BACKEND_SPEC.md).
